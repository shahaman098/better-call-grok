# Better Call Grok

Hackathon project (Grok Bot Community Engineering London, 22 Oct 2026).

Say what merch you need. Three Grok Bots design it, find the maker, negotiate the price and send you the invoice.

- **Start here:** [`START_HERE.md`](START_HERE.md)
- **Full spec:** [`BETTER_CALL_GROK_AI_DRIVEN_DEVELOPMENT_MASTER_SPEC.md`](BETTER_CALL_GROK_AI_DRIVEN_DEVELOPMENT_MASTER_SPEC.md)
- **For coding agents:** [`AGENTS.md`](AGENTS.md)

Stack: Grok Bots (agents) · `bcg` TypeScript CLI (guarded tools) · Supabase (Postgres, Storage, Edge Functions) · Telegram Bot API · Stripe (test mode) · xAI image API.
